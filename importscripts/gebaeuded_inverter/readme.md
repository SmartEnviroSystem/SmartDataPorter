Die Importkonfigurationen dienen dem Import der Daten von den Wechselrichtern der Dachanlage.

## FilesImporter
Die Dateien mit _FilesImporter lesen aus einem angegebenen Verzeichnis die Dateien ein. Sie sind nicht zum direkten Abruf der Dateien vom Wechselrichter geeignet.
